# 又一局 · 微信小程序

原生 TypeScript / WXML / SCSS 实现，与 Web 共用 `/api/v1` 和同一套账号、小组、玩家及对局数据，不使用 WebView。

## 开发与构建

```sh
pnpm --dir mini install --frozen-lockfile
pnpm --dir mini check
```

`check` 执行行为测试、严格 TypeScript 检查、SCSS/JS 编译、页面资源完整性检查；本机安装微信开发者工具时，还调用其 WXML 编译器。产物在 `mini/dist`，不入库。可在微信开发者工具直接导入 `mini/`（使用其 TypeScript/Sass 插件），或导入已编译的 `mini/dist/`。

- `miniprogram/utils/config.ts` 的 `API_ORIGIN` 默认是本地 `http://127.0.0.1:8080`，预览真机/发布前必须改为已部署的 HTTPS 域名。
- 后端配置 `app.wechat.app_id` 与 `app.wechat.secret`；AppID 必须和 `project.config.json` 一致。Secret 只在服务端配置，不能写进小程序源码。
- 在微信公众平台配置该 HTTPS 域名的 request、uploadFile、downloadFile 合法域名。小程序没有 Node 运行时依赖。
- BGG 封面可能来自外部域名；图片不可用时显示占位，组内照片始终走自己的鉴权接口。
- 本地测试在开发者工具中关闭域名校验；不要将此设置当成真机验证。
- 自动化需要开发者工具「设置 → 安全设置 → 服务端口」开启。`miniprogram-automator` 只用于本地测试。

## 登录与绑定

1. **已有邮箱账号**：首次微信登录前点「我已有邮箱账号，先绑定」，验证邮箱后将当前微信关联到原账号，沿用全部小组、对局、玩家关联。
2. **微信新用户**：使用有效试用邀请或小组邀请注册；微信注册保留邀请制，不会公开注册。
3. **微信独立账号补绑邮箱**：在「小组 → 我的账号」验证尚未注册的邮箱，之后网页邮箱登录和微信登录共用账号。
4. 已独立注册的微信账号和另一个已有邮箱账号不自动合并；遇到冲突明确提示，任何历史数据和组权限都不迁移。

小程序只在内存保留 Bearer 会话，冷启动需要再次点微信登录。登录 code、openid、微信 session_key 不落本地持久化。退出会撤销服务端会话并清除本地草稿和已下载照片。

## 已接入页面

- 回顾时间线：日期、游戏、玩家、模式、结果、回忆文字与照片筛选、分页。
- 记一局 / 编辑：个人、组队、合作，负数/小数/零/空分数，草稿恢复、幂等重试、并发冲突、再记一局。
- 对局详情：照片、评论和一层回复、删除、可撤销公开分享。
- 桌游：本组搜索、手动添加、主动 BGG 搜索/导入、中文别名、关联/合并、想玩清单。
- 桌游/玩家详情：历史、筛选与分模式统计，比例同时显示样本数。
- 小组：创建/加入/切换、邀请、昵称玩家、关联审批、成员移除、组主转让、退出、备份。
- 聚会相册、月度/年度回顾与图片分享卡片、回收站和通知。

照片选择保留原始大小校验（2 MiB），顺序转换为最长边 1600px JPEG 后上传。失败照片可重试或移除，不阻止保存其他内容。私有照片使用带 Bearer 的下载，不能直接把私有接口 URL 交给 image 组件。

## 可重复的开发者工具验证

先在一个终端运行 `./scripts/mini-fixture.sh`，再连接开发者工具：

```sh
/Applications/wechatwebdevtools.app/Contents/MacOS/cli auto --project "$PWD/mini" --auto-port 9420
node mini/scripts/smoke.mjs
```

测试脚本先检查后端是 `mini-ui-fixture`，再操作真实原生页面及真实 API；模拟微信临时 code、选图、确认弹窗，外部邮件使用测试收件箱，不向真实联系人发送消息。需要全新测试数据时，停止 fixture 并重启。可通过 `WECHAT_AUTO_WS` 指定其它自动化端口。

2026-09-25 已在本机开发者工具跑通：首次绑定已有邮箱、三种模式、负分/零分、图片处理上传与下载、评论、编辑、公开分享投影/撤销、回收站恢复、桌游架、聚会相册、回顾卡片生成。自动化只是操作验证，不代表真实用户 60 秒录入目标。

## 验收边界

微信平台 `code2Session` 与真机 HTTPS 域名、上传、下载、相册授权仍需配置真实 AppSecret 和域名后联调。隔离测试使用测试专用微信适配器，不代表已完成微信平台授权验证。未提交、上传、发布或部署小程序。
